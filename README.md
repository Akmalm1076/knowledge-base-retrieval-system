# Knowledge Base Retrieval System

An AI-powered RAG (Retrieval-Augmented Generation) backend system built using FastAPI, PostgreSQL + pgvector, and Gemini API.

## Features
- PDF document ingestion
- Vector embeddings
- Hybrid retrieval
- Document-specific search
- Gemini-powered response generation
- FastAPI backend APIs

## Tech Stack
- FastAPI
- PostgreSQL
- pgvector
- Sentence Transformers
- Gemini API
- Python

## Status
Backend core implementation completed.
